For the setup guide (PLAN 9.3) and the Google Play listing (PLAN 9.1), taken on 2026-10-04 from a fresh install of the release build on the GrapheneOS phone. Server addresses and private photos are censored. Everything here is public.

In `docs/images/setup/`, all in place: the build number, setup step 1 and its computer step, the terminal, Shizuku's pairing (two shots), Shizuku running and its prompt, USB debugging (two shots), the folders step, the photos permission, the keyboard settings, the picker's cloud settings and the home screen.
