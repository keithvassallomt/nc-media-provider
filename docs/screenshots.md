# Screenshots to take

For the setup guide (PLAN 9.3) and the Google Play listing (PLAN 9.1). Portrait phone screenshots (power and volume down) are fine as they are. Everything here ends up public, so keep server addresses, email addresses and private photos out of shot.

## Setup guide

Save these in `docs/images/setup/` under exactly these names.

| File | What to capture |
|---|---|
| `app-picker-step.png` | Setup step 1 with the Shizuku and computer options. **Details and troubleshooting > Go through setup again** gets back to it. |
| `build-number.png` | Settings > About phone, scrolled so **Build number** shows. |
| `shizuku-pairing.png` | Wireless debugging's **Pair device with pairing code** dialog with a code, and Shizuku's notification asking for it. Two shots are fine: `shizuku-pairing-1.png` and `-2.png`. |
| `shizuku-running.png` | Shizuku's main screen saying it is running. |
| `shizuku-allow.png` | Shizuku asking whether to allow NC Media Provider. Revoke the app in Shizuku's list of authorised apps to see it again. |
| `usb-debugging-prompt.png` | Android's **Allow USB debugging?** prompt, on a phone or computer not yet authorised. |
| `app-computer-step.png` | Setup step 1 with **With a computer** chosen: the commands and the Copy button. |
| `terminal-commands.png` | A terminal after running the five commands, ending with `set_cloud_provider_result=true`. |
| `picker-cloud-settings.png` | The picker's cloud settings with NC Media Provider selected (**Details and troubleshooting > Photo picker settings**). |
| `home.png` | The app's home screen with the **In the picker** card. |

## Google Play listing

Save these in `docs/images/play/`. Play takes 2 to 8 phone screenshots, each side between 320 and 3,840 px; these photos are public on the store page, so use a library you're happy to show.

| File | What to capture |
|---|---|
| `1-picker.png` | The system picker with Nextcloud photos mixed in with the phone's (**Try the picker** on the home screen). |
| `2-albums.png` | The picker's albums, with Nextcloud albums among them. |
| `3-home.png` | The app's home screen. |
| `4-keyboard.png` | The photo keyboard open in a chat app, on the Albums or People tab. |
| `5-storage.png` | The Storage screen with the pre-cache slider. |
| `6-setup.png` | The setup checklist, partly done. |
| `7-people.png` | Optional: the People section on a phone with the newer picker (a stock Pixel). |

Made without the phone: the 512×512 icon and the 1024×500 feature graphic.

## Google Play declaration video

Play asks for a short video with the foreground service declaration (see [play-notes.md](play-notes.md)): a screen recording, uploaded as an unlisted YouTube video, showing a large Nextcloud video picked in an app (Messenger or Element, say) and the **Sending from Nextcloud** notification while it is read. Thirty seconds is plenty.
